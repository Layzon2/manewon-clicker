# Manewon Clicker

Милый, красивый и слегка бессмысленный кликер, в котором нужно бесконечно нажимать на **MANEWON** и собирать бесполезные **Note Coins**.

## 🎮 Как играть
- Нажимайте на большую кнопку **MANEWON** в центре экрана.
- За каждый тап начисляется 1 Note Coin.
- Счётчик вверху обновляется мгновенно.
- При каждом нажатии кнопка пружинит, рядом появляется `+1 Note Coin`.

## 🛒 Магазин тем
Покупайте темы оформления за Note Coins:
- Тёмный лес (бесплатно)
- Пастельный рассвет (50)
- Неоновый кибер (150)
- Закат в пустыне (300)
- Глубокий океан (500)

## 🔑 Секретная тема Soundgoodizer
В магазине есть поле для промокода. Введите **`goodizer`** — разблокируется секретная тема с фоном и текстом **FUCKSOUND**.

## 🎨 Скины кнопки
Меняйте внешний вид центральной кнопки:
- Классика (бесплатно)
- Кекс (100)
- Неон (250)
- Радуга (400)
- Зубила (666)

## 🏆 Достижения
8 достижений: от первого тапа до miliona Note Coins.

## 🎵 Музыка
Фоновая мелодия (или синтезатор-фолбэк, если файл не загрузился) с регулировкой громкости. Запускается после первого взаимодействия.

## ⚙️ Админ-панель
Кнопка **🔧** в левом нижнем углу — управление монетами, кликами, темами, импорт/экспорт сохранения.

## 💾 Сохранение
Прогресс хранится в LocalStorage и не сбрасывается при обновлении страницы.

## 📱 Технологии
- HTML5 + CSS3 + JavaScript (чистый, без библиотек)
- Web Audio API для звуков и синтезатора
- Адаптивная вёрстка под мобильные устройства
- GitHub Pages для хостинга

## 🚀 Запуск
Просто откройте `index.html` в браузере.
